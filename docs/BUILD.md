# Building SeeBrowser

## Prerequisites

| Tool | Version | Notes |
|---|---|---|
| Rust | stable (via [rustup](https://rustup.rs)) | `rustup default stable` |
| Node.js | 20+ | includes npm |
| Windows only | MSVC Build Tools + WebView2 Runtime | WebView2 ships with Windows 11 / Edge; the SeeBrowser installer bootstraps it if missing |
| Linux only | `libwebkit2gtk-4.1-dev libappindicator3-dev librsvg2-dev patchelf` | `sudo apt install …` |
| macOS only | Xcode Command Line Tools | `xcode-select --install` |

## Development

```bash
npm install
npm run tauri dev        # full app with hot-reload
npm run dev              # browser UI only, in "web demo" mode (iframe tabs)
```

The web-demo mode (plain `npm run dev`) is handy for UI work: the same
chrome UI runs in any browser; tabs use iframes and storage uses
localStorage. Some sites refuse iframe embedding there — the desktop app
has no such limit.

## Production build (installers)

```bash
npm run tauri build
```

Outputs (in `src-tauri/target/release/bundle/`):

- **Windows:** `nsis/SeeBrowser_*_x64-setup.exe`, `msi/SeeBrowser_*.msi`
- **macOS:** `dmg/SeeBrowser_*.dmg`, `macos/SeeBrowser.app`
- **Linux:** `appimage/SeeBrowser_*.AppImage`, `deb/SeeBrowser_*.deb`

## Releasing (maintainers)

Releases are fully automated by GitHub Actions:

```bash
# bump version in package.json + src-tauri/Cargo.toml + src-tauri/tauri.conf.json, then:
git tag v1.0.0
git push origin v1.0.0
```

`.github/workflows/release.yml` builds all three platforms and publishes a
GitHub Release with the installers. Every push also runs
`.github/workflows/build.yml`, whose artifacts can be downloaded from the
run page. The website (`website/`) deploys to GitHub Pages via
`.github/workflows/pages.yml` and automatically links the latest release.

## Icons

Master icon: `src-tauri/icons/app-icon.png` (1024×1024, generated by
`scripts/make-logo.py`, needs `pip install pillow`). Regenerate all
platform sizes with:

```bash
python3 scripts/make-logo.py
npm run icons            # = tauri icon src-tauri/icons/app-icon.png
```

## Troubleshooting

- **`WebView2` errors on old Windows** — install the
  [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) (the
  SeeBrowser NSIS installer does this automatically for end users).
- **Linux: `webkit2gtk-4.1 not found`** — install the header package listed
  above; on some distros it is `libwebkit2gtk-4.1-dev`, on Fedora
  `webkit2gtk4.1-devel`.
- **Tabs show a blank area in dev** — make sure you run `npm run tauri dev`
  (not only the Vite server) for native webviews.
- **Servo build** — see [SERVO.md](SERVO.md).
